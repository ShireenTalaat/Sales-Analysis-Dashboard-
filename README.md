# Sales-Analysis-Dashboard

## 📊 Overview

This repository contains a comprehensive **Sales Analysis Dashboard** built with **Microsoft Power BI**. The project analyzes sales performance, product profitability, and customer demographics for a retail dataset (likely based on the AdventureWorks bicycle dataset).

The dashboard provides multiple views of the data, ranging from high-level KPIs to detailed geographic and product-specific breakdowns.

---

## 📈 Key Insights

1.  **Product Performance:** The **Mountain-200** series (specifically Black and Silver variants) dominates sales volume and revenue. The "Mountain-200 Black, 46" is the single best-selling SKU.
2.  **Geographic Distribution:** The **United States** and **Australia** are the primary markets, accounting for the vast majority of total sales revenue.
3.  **Customer Demographics:** The average customer age is roughly **34 years old**.
4.  **Revenue Trends:** There is a notable spike in revenue and profit around **Day 19** of the reporting period, suggesting a promotional event or bulk order.

## 🛠️ Tools & Technologies

*   **Microsoft Power BI:** Dashboard development and visualization.
*   **DAX (Data Analysis Expressions):** Used for calculating Total Sales, Profit, and Average Age.
*   **Microsoft Azure Maps:** For the geographic visualization of sales by country.
*   **Power Query:** For data transformation and cleaning.
